<Info>
  **前提条件**: Node.js（バージョン19以上）をインストールしてください。 <br />
  また、`docs.json` への移行を完了し、旧来の `mint.json` は削除してください。
</Info>

以下の手順でMintlifyをインストールして起動します:

**ステップ1**: Mintlifyをインストールします:

<CodeGroup>

  ```bash npm
  npm i -g mintlify
  ```

```bash yarn
yarn global add mintlify
```

</CodeGroup>

**ステップ2**: `docs.json` があるディレクトリに移動して、以下のコマンドを実行します:

```bash
mintlify dev
```

`http://localhost:3000` でドキュメントのローカルプレビューが確認できます。

### ポートのカスタマイズ

デフォルトではポート3000を使用します。`--port` フラグで変更できます。例えばポート3333で起動する場合:

```bash
mintlify dev --port 3333
```

使用中のポートを指定した場合は、自動的に次の空きポートが使用されます:

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Mintlifyのバージョン管理

CLIのバージョンはMintlifyのバージョンに対応しています。ローカルと本番環境の表示が異なる場合は、CLIを更新してください:

<CodeGroup>

```bash npm
npm i -g mintlify@latest
```

```bash yarn
yarn global upgrade mintlify
```

</CodeGroup>

## リンクの検証

CLIを使ってドキュメント内のリンク切れを確認できます:

```bash
mintlify broken-links
```

## コードフォーマット

IDEにMDX対応の拡張機能を入れることを推奨します。VSCodeをお使いの場合は、シンタックスハイライト用に[MDX VSCode拡張機能](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx)、コードフォーマット用に[Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)が便利です。

## トラブルシューティング

<AccordionGroup>
  <Accordion title='エラー: "sharp"モジュールがdarwin-arm64ランタイムで読み込めない'>

    Nodeのバージョンが古い可能性があります。以下の手順をお試しください:
    1. 現在のMintlifyを削除: `npm remove -g mintlify`
    2. Node v19以上にアップグレード
    3. Mintlifyを再インストール: `npm install -g mintlify`
  </Accordion>

  <Accordion title="問題: 不明なエラーが発生する">

    解決策: デバイスのルートにある `~/.mintlify` フォルダを削除してから、`mintlify dev` を再実行してください。
  </Accordion>
</AccordionGroup>

CLIの変更履歴は[こちら](https://www.npmjs.com/package/mintlify?activeTab=versions)で確認できます。
