## 開発環境のセットアップ

ローカルでドキュメントを編集し、公開する方法を説明します。

### 編集とプレビュー

<AccordionGroup>
  <Accordion icon="github" title="リポジトリをローカルにクローンする">
    オンボーディング時に、GitHubにドキュメント用のリポジトリが作成されています。
    リポジトリは[ダッシュボード](https://dashboard.mintlify.com)から確認できます。
    クローン手順は[こちら](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)を参照してください。
  </Accordion>
  <Accordion icon="rectangle-terminal" title="変更をプレビューする">
    変更内容が意図どおりに表示されているか確認するには、ローカルでプレビューします。

    1. [Mintlify CLI](https://www.npmjs.com/package/mintlify) をインストールします: ``` npm i -g mintlify ```
    2. `docs.json` があるディレクトリで以下を実行します: ``` mintlify dev ```
    <Note>
      旧来の `mint.json` を使用している場合は、まずCLIを最新版に更新してください:

      ```npm i -g mintlify@latest```
      次にリポジトリのルートで以下を実行します:

      ```mintlify upgrade```

      これで新しい `docs.json` に移行されます。移行後は `mint.json` を削除して構いません。
    </Note>
  </Accordion>
</AccordionGroup>

### 変更を公開する

<AccordionGroup>

<Accordion icon="message-bot" title="GitHub Appをインストールする">
  GitHub Appをインストールすると、変更をプッシュするだけで自動的にドキュメントサイトに反映されます。
  インストールリンクは[ダッシュボード](https://dashboard.mintlify.com)から確認できます。
  インストールが完了すると、リポジトリのコミットハッシュの横にチェックマークが表示されます。
</Accordion>
<Accordion icon="rocket" title="変更をプッシュする">
  [変更をコミットしてGitにプッシュ](https://docs.github.com/en/get-started/using-git/pushing-commits-to-a-remote-repository#about-git-push)すると、ドキュメントサイトに自動で反映されます。
  GitHub Appによるデプロイが確認できない場合は、[ダッシュボード](https://dashboard.mintlify.com)から手動で更新することもできます。
</Accordion>

</AccordionGroup>
